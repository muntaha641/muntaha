# Glamify - Luxury Beauty E-Commerce

A luxury Haute Beauty Atelier and E-Commerce website crafted with responsive modern design, Tailwind CSS, Google Fonts (Playfair Display & Plus Jakarta Sans), and Material Symbols.

## 🚀 Features
- **Editorial Aesthetic:** Luminous design palette with warm tones, elegant typography, and high-resolution visuals.
- **Product Categories:** Curated beauty formulations including Velvet Lipsticks, Foundations, Concealers, Radiant Blushes, Highlighters, and Skincare.
- **Interactive Elements:** AI Shade Diagnostic Matcher, Cart & Wishlist counters, and product shade selectors.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewing.

## 🛠️ How to Run Locally
Run with PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1 -Port 8000
```
Then open `http://localhost:8000` in your web browser, or double-click `index.html` directly.
